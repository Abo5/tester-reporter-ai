Seeded Defect Bench

A working page with five defects built into it on purpose. Record a session here and check whether your capture tooling found all five — and, just as importantly, whether it invented a sixth.

Every defect below is deliberate and documented. The point is not to fix them; it is to have a target whose ground truth is known, so a report can be graded rather than admired. Two of the five are invisible on screen and exist only in the markup, which is exactly the class of defect a screenshot-based tool cannot see.

Arabic renewal form

Two seeded defects: one field renders left-to-right inside a right-to-left block, and one option was never translated.

Nothing here is stored or sent anywhere. The tenant lookup calls /api/contracts/<id>, which does not exist on this host, so the request fails for real rather than being faked — a recorder should capture the status code and the error the handler throws immediately afterwards.
