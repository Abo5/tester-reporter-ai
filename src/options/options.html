Tester-Reporter-AI settings

Gemini API key

Get a key from Google AI Studio. It is stored on this machine only, in the extension's local storage, and is sent only to Google's API. It is not encrypted — anyone with access to this browser profile can read it. Use a key scoped to this purpose and revoke it if the machine changes hands.

Model

VERIFY this model id against the official Gemini model list before relying on it. This project could not confirm that gemini-3.5-flash exists; if it does not, the correct id goes in SUPPORTED_MODELS in src/shared/constants.ts.

Microphone narration

Saying what looks wrong while you test is often the single most useful piece of evidence. Chrome must grant microphone access to this extension once, from this page, before the recorder can use it.

Unknown

Off by default, on purpose. Chrome allows exactly one capture attempt per tab: if it asks for the tab's audio on a machine whose audio cannot be captured, the request fails outright and the tab is locked, so you lose the video entirely. Your spoken narration is a separate microphone stream and is never affected. Turn this on only if you need to hear the application itself, and check that a video still appears afterwards.

Video privacy

The extension removes passwords, tokens, card numbers and ID numbers from the page code and the action script before sending them. It cannot remove anything from the video. The video is a recording of your screen, and whatever was visible will be visible to the AI service.

Not given

Extra redaction patterns

One JavaScript regular expression per line, applied on top of the built-in patterns. Anything matching is replaced with [REDACTED:custom] before the evidence leaves this machine. An invalid line is skipped and reported below.

Storage

Checking…

Off by default. Silently deleting a tester's evidence is worse than a full disk, so nothing is ever removed without you choosing it.
