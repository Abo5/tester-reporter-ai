Model

gemini-3.5-flash has been exercised against the live API: it accepts the evidence bundle, video included, and returns a report in the structure this extension expects. To use a different model, add its id to SUPPORTED_MODELS in src/shared/constants.ts.

Sites this extension may record

The extension asks for no site access when you install it. Grant the sites you actually test — your staging server, your demo instance — and it can see nothing else.

You can still record on a site you have not granted: press Record and it will use the one-tab permission Chrome gives an extension you just invoked. The only thing you lose is network capture for requests the page made before you pressed Record.

    Microphone narration

    Saying what looks wrong while you test is often the single most useful piece of evidence. Chrome must grant microphone access to this extension once, from this page, before the recorder can use it.

    Unknown

    On by default, so you hear the application as well as your own narration. Chrome allows exactly one capture attempt per tab, so on the rare machine that cannot capture tab audio the whole request fails and you get no video at all. If that happens, turn this off: you lose application sounds and nothing else, because your narration is a separate microphone stream.

    Video privacy

    The extension removes passwords, tokens, card numbers and ID numbers from the page code and the action script before sending them. It cannot remove anything from the video. The video is a recording of your screen, and whatever was visible will be visible to the AI service.

    Not given

    Extra redaction patterns

    One JavaScript regular expression per line, applied on top of the built-in patterns. Anything matching is replaced with [REDACTED:custom] before the evidence leaves this machine. An invalid line is skipped and reported below.
